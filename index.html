Fan control · guide & scripts

Supermicro server fans that follow an NVIDIA GPU passed through to a VM. smfc reads the GPU temperatures from inside the VM over a locked-down SSH key, and any failure sends the fans to 100%. Built for a passive Tesla P100, works with any NVIDIA card.
